### 🚀 Projects

**🤖 [AI Research Report Agent](https://github.com/qlairon/ai-research-report-agent)** *(in progress)*
An agentic LLM workflow that turns a request into a structured, cited research report.
- Stateful **LangGraph** pipeline with typed shared state and **Pydantic**-validated outputs at every step
- Rule- and schema-based gates that stop or retry a step when its output is invalid
- Real-time web research via **Tavily**, with an evidence-tracking outline that flags unanswered questions
- **LLM-as-a-judge** scoring for faithfulness, coverage and format, with capped feedback-driven retries
- Provider-agnostic LLM layer: switch models through config alone (OpenRouter, Groq)

**🚦 [Traffic Light Optimization with Deep RL](https://github.com/qlairon/traffic-light-drl)**
A custom intersection simulator with a 4-phase signal controller and stochastic vehicle arrivals, plus a **Double DQN** agent in **PyTorch** that learns which phase to choose.
- Reward balances throughput against queue length and yellow-phase penalties
- Interactive visualization with **Streamlit** and **Plotly**

**📊 [Machine Learning Predictive Models](https://github.com/qlairon/ml-predictive-models)**
End-to-end classification and regression work: cleaning, EDA, visualization, and comparing algorithms on accuracy.
